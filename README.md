# CalculadoraSV
Esse é o projeto do trabalho da implementação de uma calculadora em SystemVerilog

Feito por:  

            - Eduardo de Oliveira de Pietro  

            - Gabriel de Carvalho Woltmann

            - Natan Duarte de Oliveira

- `/rtl` : Contém os arquivos em SystemVerilog.
- `/sim` : Exemplos de testbenches e scripts para usar com o Questa.

Para executar:

- entrar na pasta `./sim/`
- executar o comando `vsim -do sim.do`
